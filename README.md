# Coleen

A simple Zig executable that takes a screenshot of your screen every X second and divides your screen into multiple parts to match your lights setup.

Inspired by [Philips Hue Sync TV](https://www.philips-hue.com/en-us/explore-hue/propositions/entertainment/sync-with-tv/sync-app).

It uses [rustbee](https://github.com/Snoupix/rustbee) FFI C dynamic lib to comunicate with the rustbee-daemon as the bluetooth backend.

Why the name ? Simple: Col(or)(scr)een
